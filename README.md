<div align="center">
    <h1>0wl</h1>
    <p>Artificial Intelligence Geospatial Intelligence Tool</p>
</div>

0wl is a tool that uses artificial intelligence for geospatial intelligence by compiling the results of different AI models and tools.

---

> [!WARNING]
> **0wl is under active development.**
> The project is not yet fully functional and may not work as expected out of the box.
> If you'd like to contribute, feel free to open a [pull request](https://github.com/diurned/owl/pulls).
> Found a bug, vulnerability, or something unusual? Please open an [issue](https://github.com/diurned/owl/issues).

> [!NOTE]
> This project is a complete rebuild of `Fastiraz/llamap` after I have been banned from GitHub on [Fastiraz account](https://github.com/Fastiraz/) for no reason.
